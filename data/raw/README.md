# Put the dataset here

Download **HR_Job_Placement_Dataset.csv** from the Google Drive link in the project brief and save it in this folder:

    data/raw/HR_Job_Placement_Dataset.csv

(Or keep it anywhere and set the `HR_RAW_CSV` environment variable / `.env` entry to its full path.)

Expected: 50,000 rows x 26 columns (see `docs/PROJECT_DOCUMENTATION.md` for the data dictionary).
